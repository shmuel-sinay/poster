# עורך פוסטים עם Claude

סקריפט לדפדפן (userscript) שעורך פוסטים בלחיצה: מסדר את הטקסט כמו מדריך מעוצב (כותרות, רשימות, פסקאות), ושומר על הניסוח המקורי.

## התקנה

1. מתקינים בדפדפן את התוסף **Tampermonkey** (או Violentmonkey) מחנות התוספים של Chrome / Edge / Firefox.
2. נכנסים לקישור הזה, ו-Tampermonkey יציע להתקין את הסקריפט. לוחצים "התקן":
   https://raw.githubusercontent.com/shmuel-sinay/poster/main/post-editor.user.js
3. בכרום ובאדג': בהגדרות התוסף צריך להפעיל את "Allow User Scripts" (או את "מצב מפתח" בעמוד התוספים), אחרת הסקריפט לא ירוץ.

הסקריפט מתעדכן לבד מגיטהאב. כל שינוי שנכנס לענף `main` (עם מספר גרסה חדש) מגיע אוטומטית.

## שימוש

1. בפעם הראשונה: לוחצים על הכפתור הכתום ✨ בפינת הדף, מדביקים את מפתח ה-API של Claude (מ-console.anthropic.com) ולוחצים "שמור הגדרות".
2. כותבים פוסט בתיבה באתר (או מסמנים טקסט), ולוחצים ✨ או Alt+Shift+E.
3. לוחצים "ערוך עם Claude".
4. לוחצים "הכנס לשדה בדף" כדי להחליף את הטקסט בתיבה, או "העתק".

בהגדרות (⚙️) אפשר לבחור מודל, פורמט פלט (טקסט רגיל לפייסבוק/וואטסאפ, או Markdown), ולהוסיף הנחיות קבועות משלך.

המפתח נשמר רק בדפדפן, ונשלח רק לשרת של Anthropic. הוא לא נשמר במאגר הזה.

## עדכון גרסה (למפתח)

בכל שינוי בסקריפט מעלים את `@version` בראש הקובץ, אחרת Tampermonkey לא יזהה שיש עדכון.
