# עורך פוסטים עם Claude

סקריפט לדפדפן (userscript) שעורך פוסטים בלחיצה: מסדר את הטקסט כמו מדריך מעוצב (כותרות, רשימות, פסקאות), ושומר על הניסוח המקורי.

## התקנה

1. מתקינים בדפדפן את התוסף **Tampermonkey** (או Violentmonkey) מחנות התוספים של Chrome / Edge / Firefox.
2. נכנסים לקישור הזה, ו-Tampermonkey יציע להתקין את הסקריפט. לוחצים "התקן":
   https://raw.githubusercontent.com/shmuel-sinay/poster/main/post-editor.user.js
3. בכרום ובאדג': נכנסים ל-`chrome://extensions`, לוחצים "פרטים" (Details) של Tampermonkey ומפעילים את "Allow User Scripts". בגרסאות ישנות יותר מפעילים במקום זה את "מצב מפתח" (Developer mode) בפינה העליונה. בלי זה הסקריפט לא ירוץ.
4. בודקים: באתר כלשהו, האייקון של Tampermonkey צריך להראות את המספר 1 ואת "עורך פוסטים עם Claude" כפעיל.

הסקריפט מתעדכן לבד מגיטהאב. כל שינוי שנכנס לענף `main` (עם מספר גרסה חדש) מגיע אוטומטית.

## שימוש

1. בפעם הראשונה: לוחצים על הכפתור הכתום ✨ בפינת הדף, מדביקים את מפתח ה-API של Claude (מ-console.anthropic.com) ולוחצים "שמור הגדרות".
2. בפורום: בחלון כתיבת ההודעה יש כפתור ✨ בתחילת שורת הכלים. לוחצים עליו והפוסט נטען לבד. בשאר האתרים: כותבים בתיבה (או מסמנים טקסט) ולוחצים על הכפתור הכתום ✨ בצד שמאל של המסך, או Alt+Shift+E.
3. לוחצים "ערוך עם Claude".
4. לוחצים "הכנס לשדה בדף" כדי להחליף את הטקסט בתיבה, או "העתק".

## איך ה-AI מכיר את כלי העיצוב של הפורום

בכל עריכה ה-AI מקבל שני דברים:

1. **ארגז כלים**: כל כלי העיצוב של מתמחים טופ ואיך כותבים כל אחד, לפי "המדריך המלא לשימוש בפורום": פסי כותרת כהים `#anchor(...)`, ספוילר `:::`, צבע `%(#f0300e)[...]`, תיבות הערה `!!! warning`, יישור, הסתרה מאורחים, תיבות סימון, טבלאות, תפריט קישורים פנימיים ועוד. אפשר לערוך את הרשימה בהגדרות.
2. **פוסטים לדוגמה**: ה-AI לומד מפוסטים מעוצבים את הסגנון והמבנה של מדריך טוב. יש שלוש דרכים להוסיף דוגמאות:
   - **מובנות במאגר**: כל קובץ בתיקייה [`examples`](examples) שרשום ב-`examples/index.txt` נטען אוטומטית אצל כולם (מתרענן פעם ביום). כרגע יש שם את הפוסט של מכשירוט.
   - **קובץ HTML**: בהגדרות לוחצים "טען מדריך מקובץ HTML" ובוחרים קובץ ייצוא של נושא מהפורום. הסקריפט ממיר אותו חזרה לקוד המקור של הפורום (פסי כותרת, ספוילרים, צבעים וכו').
   - **קישור לנושא**: מדביקים קישור לנושא בפורום ולוחצים "משוך את קוד המקור מהפורום" (כדאי להיות מחובר לפורום).

אם המשיכה לא מצליחה, אפשר לפתוח פוסט שלך בעריכה בפורום, להעתיק את קוד המקור שלו ולהדביק בשדה "קוד המקור של הפוסטים לדוגמה".

בהגדרות (⚙️) אפשר גם לבחור מודל, לעבור לפורמט טקסט רגיל לפייסבוק/וואטסאפ, ולהוסיף הנחיות קבועות משלך.

המפתח נשמר רק בדפדפן, ונשלח רק לשרת של Anthropic. הוא לא נשמר במאגר הזה.

## עדכון גרסה (למפתח)

בכל שינוי בסקריפט מעלים את `@version` בראש הקובץ, אחרת Tampermonkey לא יזהה שיש עדכון.
